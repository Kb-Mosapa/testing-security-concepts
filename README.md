# Testing Security Concepts

Testing Security Concepts (TSC) is where I explore security concepts through theory, questioning, testing, and practice.

Rather than treating security concepts only as definitions to remember, I use this repository to document my current understanding, challenge my assumptions, and eventually test those ideas through projects and lab work.

## Security Concepts
